# ГЛИБШЕ · Море, якого немає

Українськомовна інтерактивна історія про Подільські Товтри. Статична сторінка на HTML, CSS та JavaScript, без зовнішніх шрифтів, аналітики, фреймворків чи серверних інтеграцій.

## Запуск

Потрібен Node.js 20 або новіший. У PowerShell:

```powershell
Set-Location 'C:\Dev\personal\prj\tovtry'
npm run dev
```

Відкрити http://127.0.0.1:4173. Для зупинки натиснути Ctrl+C. Якщо порт зайнятий: `$env:PORT = '4174'`, потім `npm run dev`.

Готові WebP уже включені: встановлювати залежності для перегляду не потрібно. Відкривати `index.html` через `file://` не слід: анімація завантажує кадри через HTTP.

## Зображення й анімація

- Вихідні матеріали збережено: `img/frame_001.jpg` … `img/frame_050.jpg`, а також відео `video/Landscape_transforming_v2-cutter.mp4`.
- Анімація використовує 50 наданих JPG, перетворених на WebP. MP4 не завантажується на сторінці.
- `assets/frames/desktop`: 1280×720, WebP quality 70; `assets/frames/mobile`: 800×450, quality 76.
- На старті вибирається один набір залежно від ширини вікна. При зміні орієнтації canvas перераховується; для зміни якості набору потрібно оновити сторінку.
- Прогрес скролу визначає дробову позицію між 50 кадрами. Canvas змішує сусідні зображення для м'якшого переходу. 50 кадрів не відновлюють деталі, яких немає між ними у вихідній послідовності.
- До чотирьох фонових запитів завантажують стиснені кадри. Декодований кеш обмежений десятьма зображеннями; за швидкого скролу завантажується актуальний кадр.
- На телефоні та комп'ютері hero заповнює екран із центральним кадруванням. Постер і canvas мають однакову композицію; на мобільному текст розміщений поверх пейзажу, висота враховує видиму область браузера.
- Кнопка руху й системне `prefers-reduced-motion` переводять сторінку в статичний режим. Постер та основний текст доступні також без JavaScript. Порівняння двох сцен працює через доступний із клавіатури range input.
- Якщо кадри не завантажились, залишається постер та повідомлення; основна історія доступна нижче.

## Повторна підготовка кадрів

Лише для зміни вихідних зображень потрібен Sharp:

```powershell
npm ci
npm run prepare-media
npm run check
```

Можна передати іншу папку: `npm run prepare-media -- 'C:\path\to\img'`. Скрипт перевіряє наявність рівно 50 послідовних назв. Оригінали не змінює. Трансформація MP4 більше не потрібна.

## Структура

- `index.html` — зміст, джерела, семантична структура.
- `styles.css` — оформлення, адаптивність, статичний режим.
- `app.js` — кадри, canvas, скрол, порівняння, налаштування руху.
- `scripts/serve.mjs` — локальний HTTP-сервер, прив'язаний до 127.0.0.1.
- `scripts/prepare-media.mjs` — підготовка WebP з наданих JPG.

Для майбутнього статичного розміщення достатньо `index.html`, `styles.css`, `app.js`, `favicon.svg` та `assets/`. Каталоги оригіналів `video/`, `img/`, а також `node_modules/` публікувати не потрібно. Ця версія не публікувалася онлайн.

## Перевірка першої версії

- Перевірка синтаксису JavaScript через `npm run check`.
- Браузерна перевірка ширин 390, 768 та 1440 px: горизонтального переповнення немає.
- Підтверджено показ початкового, проміжних і 50-го кадру; зворотний скрол та зміна розміру вікна.
- Підтверджено статичний режим через кнопку руху й мобільний набір зображень.
- Порівняння сцен перевірено клавішами Home/End: 0% та 100%.
- Окремий тимчасовий HTTP-сервер повертав 404 для кадрів 2–50: постер, повідомлення та текст історії залишалися доступними.
- У звичайному режимі браузер не зафіксував помилок JavaScript.
- Реальні iPhone/Android та Safari не перевірялися. Системне налаштування зменшеного руху підключене через media query; у QA перевірена ручна активація того самого статичного режиму.

У розділі 03 додано три інтерактивні точки з поясненнями, у розділі 04 — нову композицію з каньйоном та завантаженням автономної картки. ## Редакційна основа

Джерела: матеріали НПП «Подільські Товтри» про походження Товтр та геологічну будову території (посилання є на сторінці). Пейзажі позначені художніми візуалізаціями. Це не документальні фото конкретної локації й не точна наукова реконструкція. Немає вигаданих маршрутів, актуальних цін, платежів або форм, що збирають особисті дані.

## Документальний фотоатлас і нова палітра

Розділ 02 містить три документальні фотографії: міоценовий вапняк із мушлями з Ермінгена (Німеччина), скелі Нігинської товтри та панораму Подільських Товтр. Під кожним фото вказано автора, джерело й ліцензію; повний запис — у `ASSET-CREDITS.md` та `assets/traces/credits.json`. Перекодування в WebP не змінює кольорів фотографій. Фото німецького зразка явно позначене навчальним прикладом.

Перемикання підтримує мишу, дотик, клавіші Left/Right/Home/End. Кнопка «Роздивитися» відкриває велике фото; Escape або кнопка закриття повертає до атласу. Під час завантаження нового фото попереднє залишається видимим; швидкі перемикання не показують застарілий результат. За помилки фото можна повторно обрати.

Для відтворення медіа: `npm run prepare-editorial`, потім `npm run prepare-notes`. Вихідні документальні JPEG — у `img/documentary`; зображення блоку 04 — наданий файл `img/Generated Image November 02, 2026 - 12_55PM (1).jpg`. Старі надані зображення збережено.

Основні кольори інтерфейсу: слонова кістка `#f4f0e8`, теплий графіт `#242522`, темне чорнило `#292620`, бронзовий акцент `#cfb182`. Офлайн-картку також оновлено до нової палітри та нового зображення.

Поточний атлас використовує `img/documentary/fossils.png`, `limestone.jpg` та `tovtry.png`.
