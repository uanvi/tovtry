# ГЛИБШЕ · Рекомендації до преміального рівня

Огляд: 2 листопада 2026 року. Оцінено живу локальну сторінку, перший екран, пояснення, порівняння епох та фінальний блок. Нижче — дизайнерські та продуктові гіпотези. Зростання конверсії поки не вимірювалося.

## Що змінено в цій ітерації

1. Порівняння епох перетворено на маленьку експедицію: три інтерактивні точки «Рельєф / Вапняк / Життя», пояснення поруч на комп'ютері й під зображенням на телефоні. Є керування клавіатурою та повідомлення про зміну пояснення для допоміжних технологій.
2. Фінальний блок перетворено на повноекранну сцену з наданим зображенням каньйону, контрастною типографікою та прев'ю польових нотаток. Замість єдиної зовнішньої дії з'явилася корисна власна пропозиція: безкоштовна картка дослідника.
3. Створено автономну картку спостережень: збережений HTML містить саме зображення, стилі, три завдання, місце для нотаток та джерела. Працює без інтернету; має версію для друку. Це не туристичний маршрут і не платний путівник.
4. Додано компактну навігацію між чотирма главами з індикацією поточного розділу. Вона приховується на початку історії та біля фінальної інформації про проєкт.

## Напрям бренду

Сучасна цифрова природнича експозиція: один сильний пейзаж, небагато інтерфейсу, впізнаваний голос, точні факти й відчуття власного відкриття. Взаємодія повинна пояснювати щось нове. Декоративний 3D, автозвук і надмірні паралакси не є необхідними для цієї історії.

## Вимірювання та перевірка

Перевірено браузером: вибір інтерактивних точок, відповідність пояснення вибору, поточна глава навігації, відсутність горизонтального переповнення на настільному та мобільному компонуванні, HTTP 200 картки й вбудоване зображення. Перевірка синтаксису — `npm run check`. Фізичні телефони, Safari, реальні показники швидкодії та конверсії ще потребують окремого тестування.

Первинні технічні орієнтири:

- [Google web.dev: Optimize Largest Contentful Paint](https://web.dev/articles/optimize-lcp)
- [MDN: prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)
